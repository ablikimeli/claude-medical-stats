medical-statistics

在 Claude Code 里对话式完成临床数据分析

v2.0.0 . 2026-05 . 开源 . MIT License

如果你做过临床研究，大概知道这套流程有多繁琐：数据清理、正态性检验、Table 1、单因素筛选、多因素建模、非线性探索、敏感性分析......每换一个变量就要改代码重新跑。更不用说审稿人要求补充 RCS、亚组分析或倾向评分时，又得回去改脚本。

这个 Skill 在 Claude Code 里以对话方式完成上面这一整套流程，每个环节都有统计审稿人级别的质控，结果自动导出为可用的表格和图形。

核心理念：对话式分析 + 自动质控。不用记命令，不用来回切换软件，像跟统计学家聊天一样完成分析。

完整分析流程

Pipeline 一览

数据导入 → 质控与缺失值评估 → 正态性检验 → 方法推荐（交互确认） → Table 1 单因素分析 → 多因素回归 → RCS 非线性分析 → 敏感性分析 → 结果汇总与导出

每个步骤都会先推荐方法并说明理由，等你确认后再执行。如果坚持自选方法，结果中会标注「用户指定」。

为什么值得一试

  • 对话式分析：不用写代码，不用记命令，自然语言完成分析
  • 自动质控：正态性检验 → 方法推荐 → 效应量报告 → 模型诊断，每一步都有检查
  • 多格式导出：表格自动导出 CSV/Excel/Word，图形自动导出 PNG/PDF
  • 交互确认：统计方法先推荐、解释理由，你确认后再执行
  • 方法全面：支持回归、生存、RCS、PSM、中介、敏感性分析等全流程
  • 可复现：所有分析代码可追溯
提醒：这个工具能帮你完成规范的统计分析，但不能替代对方法的真正理解。最终的方法选择和结果解释仍需要你结合临床背景自行判断。
