# 医学统计方法参考指南

## 1. 变量类型与描述方式

| 变量类型 | 正态分布 | 非正态分布 |
|:---------|:---------|:-----------|
| 连续变量 | Mean ± SD | Median (Q1, Q3) |
| 分类变量 | n (%) | n (%) |

## 2. 单因素分析方法选择

### 2.1 两组比较

| 变量类型 | 正态+方差齐 | 正态+方差不齐 | 非正态 |
|:---------|:-----------|:-------------|:-------|
| 连续变量 | 独立样本t检验 | Welch t检验 | Wilcoxon秩和检验 |
| 分类变量 | χ²检验 | Fisher精确检验 | Fisher精确检验 |
| 等级变量 | - | - | Cochran-Mantel-Haenszel |

### 2.2 多组比较

| 变量类型 | 正态分布 | 非正态 |
|:---------|:---------|:-------|
| 连续变量 | ANOVA (F检验) | Kruskal-Wallis H检验 |
| 事后检验 | Tukey HSD / Bonferroni | Dunn检验 |
| 分类变量 | χ²检验 | Fisher精确检验 |

### 2.3 配对比较

| 变量类型 | 正态 | 非正态 |
|:---------|:-----|:-------|
| 连续变量 | 配对t检验 | Wilcoxon符号秩检验 |
| 分类变量 | McNemar检验 | McNemar检验 |

### 2.4 相关性分析

| 变量类型 | 正态 | 非正态 |
|:---------|:-----|:-------|
| 两连续变量 | Pearson相关 | Spearman秩相关 |
| 等级变量 | - | Kendall tau |

## 3. 多因素分析方法选择

| 结局变量类型 | 回归方法 | 效应值 | 适用场景 |
|:------------|:--------|:-------|:---------|
| 二分类 | Logistic回归 | OR (95% CI) | 患病/未患病，死亡/存活 |
| 有序多分类 | 有序Logistic回归 | OR (95% CI) | 轻/中/重 |
| 无序多分类 | 多项Logistic回归 | RRR (95% CI) | A/B/C型 |
| 生存时间 | Cox比例风险回归 | HR (95% CI) | 生存分析 |
| 连续变量 | 线性回归 | β (95% CI) | 血压值、评分 |

## 4. 模型诊断与假设检验

### 4.1 Logistic回归
- **Hosmer-Lemeshow 拟合优度检验**: P > 0.05 表示拟合良好
- **ROC曲线**: AUC > 0.7 表示有区分度
- **VIF**: VIF < 10 表示无严重共线性

### 4.2 Cox回归
- **比例风险假设**: Schoenfeld残差检验 P > 0.05
- **AIC/BIC**: 越小越好

### 4.3 线性回归
- **残差正态性**: Shapiro-Wilk P > 0.05
- **残差独立性**: Durbin-Watson 统计量 ≈ 2
- **方差齐性**: Breusch-Pagan检验 P > 0.05
- **VIF**: VIF < 10

## 5. 限制性立方样条 (RCS)

### 节点选择建议
| 样本量 | 推荐节点数 | 位置 |
|:-------|:----------|:-----|
| n < 30 | 3 | 第10/50/90百分位 |
| 30 ≤ n < 100 | 4 | 第5/35/65/95百分位 |
| n ≥ 100 | 5 | 第5/27.5/50/72.5/95百分位 |

### 解读
- **P for overall < 0.05**: 变量与结局显著相关
- **P for non-linear < 0.05**: 存在非线性关系
- **OR/HR = 1 的交叉点**: 可能的阈值/拐点

## 6. 变量筛选策略

| 方法 | 说明 |
|:-----|:------|
| Enter法 | 全部变量一次性纳入 |
| 向前法 | 逐个添加显著变量 |
| 向后法 | 逐个剔除不显著变量 |
| 逐步法 | 结合向前和向后 |
| Lasso | 高维数据自动筛选 |

## 7. P值阈值与标注

| P值范围 | 标注 | 意义 |
|:--------|:----|:-----|
| P < 0.001 | *** | 极显著 |
| P < 0.01 | ** | 高度显著 |
| P < 0.05 | * | 显著 |
| P < 0.10 | + | 边缘显著 |
| P ≥ 0.10 | ns | 不显著 |

## 8. 常用统计量指标

| 指标 | 缩写 | 含义 |
|:------|:-----|:------|
| 均值 | Mean | 算术平均数 |
| 标准差 | SD | 离散程度 |
| 标准误 | SE | 抽样误差 |
| 中位数 | Median | 第50百分位 |
| 四分位距 | IQR | Q3 - Q1 |
| 比值比 | OR | Logistic回归效应值 |
| 风险比 | HR | Cox回归效应值 |
| 回归系数 | β | 线性回归效应值 |
| 95%置信区间 | 95% CI | 效应值范围 |

## 9. 常见错误与修正

| 错误 | 正确做法 |
|:-----|:---------|
| 非正态数据用t检验 | 改用Wilcoxon秩和检验 |
| 方差不齐用t检验 | 改用Welch t检验 |
| 理论频数<5用χ²检验 | 改用Fisher精确检验 |
| 配对数据用独立检验 | 改用配对检验 |
| 多组比较直接做两两t检验 | 先做ANOVA，再用事后检验 |
| 分类变量做线性回归 | 改用Logistic回归 |
