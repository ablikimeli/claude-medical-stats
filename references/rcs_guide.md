# 限制性立方样条 (RCS) 参考指南

## 什么是限制性立方样条？

限制性立方样条（Restricted Cubic Spline, RCS）是一种灵活的参数化方法，用于拟合连续变量与结局之间的**非线性关系**。相比传统方法（如将连续变量分类），RCS能更准确地反映剂量-反应关系。

## 核心优势

1. **无需预先假设函数形式** — 数据驱动拟合
2. **在两端限制为线性** — 避免尾部波动过大
3. **可同时检验整体关联和非线性** — P for overall 和 P for non-linear
4. **可调整协变量** — 排除混杂因素影响

## 数学模型

RCS使用分段多项式，在节点(knots)间拟合三次函数，在两端限制为线性：

```
f(x) = β₀ + β₁x + β₂(x - k₁)³₊ + β₃(x - k₂)³₊ + ... + β_{k-1}(x - k_{k-2})³₊
```

其中 (u)³₊ = max(0, u)³

## 节点选择

### 一般原则
- **3个节点**: 最小自由度，适合小样本，位于 10/50/90 百分位
- **4个节点**: 推荐默认值，位于 5/35/65/95 百分位
- **5个节点**: 大样本，位于 5/27.5/50/72.5/95 百分位

### Harrell 建议
- 数据集足够大时，使用 4-5 个节点
- 数据量有限时，3 个节点也能提供较好的拟合

## 解读要点

### 图形解读
- **纵坐标**: OR 或 HR（通常以中位数或特定参考值为参照）
- **横坐标**: 连续变量取值
- **阴影区域**: 95% 置信区间
- **虚线**: OR/HR = 1 的参考线

### 关键P值
- **Overall P**: 变量与结局是否存在任何关联
- **Nonlinear P**: 关联是否存在非线性成分

### 常见模式
| 模式 | 描述 | 举例 |
|:-----|:-----|:------|
| L型 | 急剧下降后趋于平稳 | 血压与不良事件 |
| J型 | 先平稳后急剧上升 | 饮酒量与死亡率 |
| U型 | 两头高中间低 | BMI与死亡率 |
| S型 | 缓慢-加速-饱和 | 药物剂量与效应 |
| 倒U型 | 中间高两头低 | 认知功能与年龄 |

## 应用场景

- **流行病学**: 暴露-反应关系（BMI与死亡率）
- **临床研究**: 生物标志物与预后（血糖与并发症）
- **药物剂量**: 剂量-效应关系
- **环境健康**: 污染物浓度与健康效应

## 注意事项

1. **节点位置**: 避免极端百分位，以防数据稀疏导致估计不稳
2. **过度拟合**: 节点数过多可能导致过度拟合
3. **外推**: RCS在数据范围外不可靠
4. **交互作用**: 可引入乘积项分析修饰效应
5. **报告**: 必须报告节点数、位置和选择依据

## 与替代方法比较

| 方法 | 优势 | 劣势 |
|:-----|:-----|:------|
| RCS | 灵活、两端线性 | 需选择节点 |
| B-spline | 数值稳定 | 两端不控制 |
| 自然样条 | 与RCS类似 | 节点位置灵活 |
| 分类变量 | 简单直观 | 损失信息、选择偏倚 |
| 分数多项式 | 自动选择阶数 | 可选形式有限 |
